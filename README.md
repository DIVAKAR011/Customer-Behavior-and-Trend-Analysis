# 📊 Customer Behavior and Trend Analysis

A data analytics project focused on understanding customer purchasing behavior, spending patterns, product preferences, customer loyalty, discount usage, subscription behavior, and other business insights using **Python, SQL, MySQL, and Power BI**.

---

## 📌 Project Overview

This project analyzes a customer shopping dataset containing **3,900 records**.

The project follows a complete data analytics workflow:

**Data Cleaning → Data Transformation → SQL Analysis → Business Insights → Power BI Dashboard**

Python and Pandas were used to clean and preprocess the raw dataset.  
The cleaned data was then stored in MySQL and analyzed using SQL to answer important business questions. Finally, Power BI was used to create an interactive dashboard for visualization and reporting.

---

## 🎯 Objectives

- Clean and preprocess customer shopping data
- Handle missing and inconsistent data
- Perform exploratory data analysis
- Transform raw data into an analysis-ready format
- Store cleaned data in MySQL
- Perform business analysis using SQL
- Analyze customer purchasing behavior
- Identify customer loyalty and repeat-purchase patterns
- Analyze subscription and discount behavior
- Compare revenue across different customer segments
- Create an interactive Power BI dashboard

## 🧹 Data Cleaning & Preprocessing

The raw dataset was cleaned and transformed using Python and Pandas.

### Steps Performed

- Loaded the dataset using Pandas
- Inspected dataset structure and data types
- Checked missing values
- Analyzed descriptive statistics
- Handled missing review ratings
- Standardized column names
- Created customer age groups
- Converted purchase frequency into numerical day intervals
- Checked redundant information
- Removed unnecessary columns
- Prepared the final dataset for SQL analysis

### Missing Value Handling

The `Review Rating` column contained missing values.

Instead of removing those records, missing ratings were filled using the **median rating of the corresponding product category**.

🔍 SQL Analysis

SQL was used to answer important business questions from the cleaned customer dataset.

Business Questions
1. What is the total revenue generated by each gender?
2. Which customers used discounts but still spent above the average purchase amount?
3. Which are the top 5 products based on average review rating?
4. How does average purchase amount differ between Standard and Express shipping?
5. How do subscribed and non-subscribed customers differ in spending and revenue?
6. Which products have the highest discount application rate?
7. How many customers belong to New, Returning, and Loyal segments?
8. What are the top 3 most purchased products within each category?
9. What is the relationship between repeat purchases and subscription status?
10. Which age group generates the highest revenue?
